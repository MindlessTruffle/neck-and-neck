# Asset credits

- Original giraffe athlete, armature, pavilion, stadium details, and procedural effects: created for this game using Blender MCP and Three.js.
- [Kenney Input Prompts](https://kenney.nl/assets/input-prompts), version 1.5A: actual keyboard and mouse PNG assets used in the match setup and pause controls. License: Creative Commons Zero; bundled at `public/kenney/controls/License.txt`.
- [Kenney Nature Kit](https://kenney.nl/assets/nature-kit), version 2.1: actual local GLB trees, rocks, shrubs, flowers, plank fences/gates, signs, mushrooms, logs and stumps used around the stadium. Includes the fall oak, flower-bed and camp details added to the meadow. License: Creative Commons Zero; bundled at `public/kenney/nature/License.txt`.
- Lilita One, DM Sans and Outfit: bundled fonts under SIL Open Font Licenses; see `public/fonts/`.
- Original UI illustrations: giraffe knight crest, duel emblems, trophy and pause artwork. All interface art was created for this game.
- Music: **Juhani Junkala / SubspaceAudio, “Chiptune Adventures — Stage 1”**, from [4 Chiptunes (Adventure)](https://opengameart.org/content/4-chiptunes-adventure). The composer's original 41.14288-second seamless Ogg loop is bundled, with a 128 kbps MP3 compatibility conversion. License: **CC0**, stated by the composer in the original archive's `INFO.txt`, copied to `public/audio/licenses/Juhani-Junkala-CC0.txt`. Composer: [juhanijunkala.com](https://juhanijunkala.com/).
- Contact and movement samples: [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds), version 1.0. Selected soft/generic/punch/grass-footstep recordings provide bump, set, spike, block and dive sounds. License: CC0; original license at `public/audio/licenses/Kenney-Impact-CC0.txt`.
- UI and ability samples: [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds), version 1.0. `click_001` and `confirmation_001` provide menu clicks and ability activation. License: CC0; original license at `public/audio/licenses/Kenney-Interface-CC0.txt`.
- Point jingle: [Kenney Music Jingles](https://kenney.nl/assets/music-jingles), `jingles_PIZZI11`. License: CC0; original license at `public/audio/licenses/Kenney-Jingles-CC0.txt`.
- The eight selected Kenney recordings were converted from Ogg to mono 22,050 Hz, 16-bit PCM WAV for broad browser support. Exact source filenames and conversions are listed in `public/audio/SOURCES.md`.
- Additional rising volley notes, airy anticipation, and the offline music/SFX fallback are original Web Audio synthesis. Real stock samples replace, rather than double, their synthesized equivalents when loaded.

Kenney logos are not used. No remote asset requests occur during gameplay.
