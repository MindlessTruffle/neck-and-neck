# Loading mascot

`cloud-giraffe-loading.png` was generated with OpenAI image generation in generate mode, transparent background. It contains four frames in one horizontal sheet, each 543 × 724 pixels. CSS animates the frames without a GIF decoder or per-frame JavaScript; reduced-motion uses a still frame.

## Prompt

Create a polished indie cartoon volleyball game's animated loading mascot SPRITE SHEET. Transparent background. Exactly FOUR equal square animation frames in a single horizontal row, no gutters, 4:1 aspect ratio. Each frame contains the SAME adorable golden giraffe with brown patches, big goofy muzzle and tiny horns, curled sitting on a fluffy white cloud, bouncing a turquoise and cream volleyball with its head. Thick dark brown clean outlines, painterly cel shading, warm sunlight, mint highlights, high quality hand-painted videogame 2D art. Giraffe and cloud stay in precisely same position and scale across frames; only floppy neck and ball bob up and down smoothly through a loop. All art within each frame with generous transparent padding. NO TEXT, no letters, no numbers, no labels, no borders. Readable silhouette at 160 pixels. Four consistent animation frames left to right.

The output was 2172 × 724 rather than the requested square-frame layout; the animation uses its actual 3:4 frame ratio.
